# Спецификация: кредитный калькулятор

## Цель и границы

Рассчитать ориентировочный аннуитетный платёж по сумме, ставке и целому сроку в месяцах. Комиссии, страховки, досрочное погашение, хранение данных и финансовые рекомендации не входят.

## Сценарии

- 3 000 000 ₽, 16%, 240 месяцев → 41 738 ₽.
- 120 000 ₽, 0%, 12 месяцев → 10 000 ₽.
- Ошибочный ввод → сообщение без расчёта.

## Условия готовности

- Все сценарии подтверждены тестами.
- Данные остаются в браузере.
- Команда `npm run check` завершается без ошибок.
- Сначала принято решение по ревью аналитика, затем проведено техническое ревью.

# Ступень 1-ИИ — подготовка спецификации

**Ветка:** параллельное расширение базовой ступени 1. Она не обязательна для перехода к базовой ступени 2.

Сначала выполните корневой быстрый старт. Все npm-команды запускайте из корня репозитория.

## Сделайте по порядку

1. Прочитайте базовую спецификацию в `../01-template-git/specification.md`.
2. Откройте `ai/request.md` и убедитесь, что в запросе нет секретов и корпоративных данных.
3. Сопоставьте предложения ИИ из `ai/draft-review.md` со спецификацией.
4. Самостоятельно примите или отклоните каждое предложение.
5. Из корня запустите `npm run check`.
6. Добавьте в Pull Request ссылку на журнал решений.

## Результат

К результату базовой ступени 1 добавлен проверяемый журнал: задача для ИИ, его предложения и решения человека.

ИИ не утверждает требования и не заменяет человеческую проверку.

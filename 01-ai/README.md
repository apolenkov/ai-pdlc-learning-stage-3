# Ступень 1-ИИ — подготовка спецификации

**Ветка:** параллельное расширение базовой ступени 1. Она не обязательна для перехода к базовой ступени 2.

Сначала выполните корневой быстрый старт. Все npm-команды запускайте из корня репозитория.

OpenSpec CLI на этой ступени не используется. Структура [`specification.md`](specification.md) совпадает с базовой ступенью 1, а ИИ добавляет только проверяемый черновик и журнал решения человека.

## Сделайте по порядку

1. Прочитайте [базовую спецификацию](../01-template-git/specification.md).
2. Откройте [`ai/request.md`](ai/request.md) и убедитесь, что в запросе нет секретов и корпоративных данных.
3. Сопоставьте предложения ИИ из [`ai/draft-review.md`](ai/draft-review.md) со спецификацией.
4. Самостоятельно примите или отклоните каждое предложение.
5. Из корня запустите `npm run check`.
6. Добавьте в Pull Request ссылку на журнал решений.

## Результат

Критерии человеческой приёмки совпадают с базовой ступенью 1: спецификация, наблюдаемый результат, тесты и локальная обработка данных. Задача для ИИ, его предложения и решения человека сохраняются как доказательство способа подготовки, а не как новый критерий результата.

ИИ не утверждает требования и не заменяет человеческую проверку.

# Добавить синтетический кредитный калькулятор

## Why

Учебному маршруту нужен один наблюдаемый результат, на котором можно проверить понимание спецификации, ревью и связи требований с реализацией.

## What Changes

- Добавить локальный аннуитетный калькулятор.
- Зафиксировать обычный, нулевой и ошибочный сценарии.
- Добавить автоматические тесты и воспроизводимую сборку.
- Запретить сохранение и внешнюю передачу введённых данных.

## Capabilities

### New Capabilities

- `credit-calculator`: локальный расчёт и проверяемая обработка ошибок.

### Modified Capabilities

- None.

## Impact

- Только синтетический клиентский пример.
- Новых внешних сервисов и рабочих данных нет.
- Результат проверяется командой `npm run check`.

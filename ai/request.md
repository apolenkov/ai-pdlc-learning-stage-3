# ИИ-предпроверка ступени 3

В корне репозитория откройте OpenCode с разрешённым корпоративным агентом и скопируйте сообщение:

```text
Прочитай README.md, docs/course/stage-2-transfer.md,
docs/course/requirements-traceability.md,
openspec/specs/credit-calculator/spec.md и весь активный Change
openspec/changes/add-reset-and-years-term.

Проведи только критическое review документов. Проверь происхождение
личного specification.md по полному SHA и матрицу для каждого требования:
baseline или Change → сценарий → незавершённая task → проверка результата.

Убедись, что очистка предыдущего результата при ошибке остаётся
подтверждённым baseline. Проверь, что активный Change сохраняет ввод
целого срока в месяцах, добавляет переключатель «месяцы / годы» без
автоматического расчёта и задаёт режим лет с шагом 0,5, default 20 лет
и переводом в целые месяцы. Reset должен работать в обоих режимах,
сохранять выбранный режим, возвращать 3 000 000 ₽, 16% и срок
240 месяцев либо 20 лет, очищать ошибки и результаты без auto-recalc.

Найди потерянные сценарии, ложные заявления о реализации, закрытые tasks,
непроверяемые критерии и противоречия. Для каждого замечания укажи файл
и причину. Ничего не исправляй, не запускай Apply, не меняй код и не
выдавай вывод ИИ за review аналитика или разработчика.
```

После обсуждения внесите только принятые правки, повторите проверки README и передайте актуальный diff двум людям.

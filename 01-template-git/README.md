# Ступень 1 — шаблон в Git

**Ветка:** базовая. С неё начинается цепочка `1 → 2 → 3`.

Сначала выполните раздел «Старт с чистого компьютера» в корневом `README.md`. Устанавливайте зависимости и запускайте npm-команды только из корня репозитория.

OpenSpec CLI на этой ступени не используется. Вы вручную заполняете один файл [`specification.md`](specification.md):

| Раздел Markdown | Будущий артефакт OpenSpec |
|---|---|
| Цель и границы | `proposal` |
| Требования и сценарии | `specs` |
| Проектные замечания | `design` |
| Открытые вопросы и условия готовности | `tasks` |

## Цель

Описать изменение до реализации и хранить принятую версию рядом с кодом.

## Сделайте по порядку

1. Из корня откройте папку: `cd 01-template-git`.
2. Прочитайте [`specification.md`](specification.md).
3. Проверьте цель, границы, сценарии и условия готовности.
4. Откройте <http://127.0.0.1:4173/01-template-git/>.
5. Введите 3 000 000 ₽, 16% и 240 месяцев.
6. Убедитесь, что ежемесячный платёж равен 41 738 ₽.
7. Вернитесь в корень: `cd ..`.
8. Запустите `npm run check`.
9. Зафиксируйте изменение в Git и добавьте ссылку на Pull Request в учебную задачу Jira.

## Результат

- принятая Markdown-спецификация;
- работающий калькулятор;
- автоматические проверки без ошибок;
- ссылка из Jira на версию в Git.

# Ступень 3-ИИ — OpenSpec с общим контекстом

**Ветка:** параллельное расширение базовой ступени 3. Она не требует прохождения предыдущих ИИ-вариантов.

Сначала выполните корневой быстрый старт и проверьте локальный OpenSpec 1.11.0. Все npm-команды запускайте из корня репозитория.

Вариант использует ту же полную цепочку `proposal → specs → design → tasks`, что и базовая ступень 3. ИИ не меняет условия готовности и не заменяет два человеческих ревью.

## Порядок

1. Прочитайте `CONTEXT.md` и `openspec/config.yaml`.
2. Проследите завершённое изменение: [`proposal`](openspec/changes/archive/2026-08-31-add-credit-calculator/proposal.md) → [`specs`](openspec/changes/archive/2026-08-31-add-credit-calculator/specs/credit-calculator/spec.md) → [`design`](openspec/changes/archive/2026-08-31-add-credit-calculator/design.md) → [`tasks`](openspec/changes/archive/2026-08-31-add-credit-calculator/tasks.md).
3. Передайте ИИ только обезличенную задачу и разрешённый контекст из `ai/request.md`.
4. Проверьте предложения по `ai/decision-log.md`.
5. Получите решение аналитика, затем решение разработчика или архитектора.
6. Из корня выполните `npm run check`.

## Результат

Критерии человеческой приёмки совпадают с базовой ступенью 3. Аналитик, архитектор и агент используют одинаковые термины и границы; решения ИИ прослеживаются, а требования, код и результат принимают люди.

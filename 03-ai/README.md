# Ступень 3-ИИ — OpenSpec с общим контекстом

**Ветка:** параллельное расширение базовой ступени 3. Она не требует прохождения предыдущих ИИ-вариантов.

Сначала выполните корневой быстрый старт и установите OpenSpec 1.11.0. Все npm-команды запускайте из корня репозитория.

## Порядок

1. Прочитайте `CONTEXT.md` и `openspec/config.yaml`.
2. Посмотрите действующую спецификацию в `openspec/specs/`.
3. Передайте ИИ только обезличенную задачу и разрешённый контекст из `ai/request.md`.
4. Проверьте предложения по `ai/decision-log.md`.
5. Получите решение аналитика, затем решение разработчика или архитектора.
6. Из корня выполните `npm run check`.

## Результат

Аналитик, архитектор и агент используют одинаковые термины и границы. Решения ИИ прослеживаются, а требования, код и результат принимают люди.

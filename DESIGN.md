# Устройство ступени 3

Одна реализация кредитного калькулятора на TypeScript и Vite. Код находится в src, тесты — в test, страница — index.html. Разделение на базовую и ИИ-копию приложения не требуется: отличается способ review.

OpenSpec работает локально: openspec/specs описывает текущее поведение, openspec/changes содержит планы и историю. Для этой ступени достаточно клонировать один репозиторий.

Расчёт выполняется в браузере. При ошибочном вводе поля получают сообщения, результаты очищаются до «—». Код сервиса отвечает за реализацию; спецификация задаёт наблюдаемый результат.

npm run check проверяет типы, модульные тесты, локальные ссылки, ограничения публикации, OpenSpec и сборку. Ручная проверка интерфейса описана в README и дополняет эти проверки.

Исходные шесть учебных вариантов сохранены в Git-истории до выделения самостоятельных репозиториев. Совпадение разных вариантов больше не является критерием приёмки.

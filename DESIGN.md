# Решения по устройству примера

## Что создаём

- Учебный репозиторий для аналитиков и архитекторов без корпоративных данных и секретов.
- Один кредитный калькулятор в шести накопительных вариантах процесса.
- Самостоятельный вход в каждую ступень: инструкция, результат и проверка.

## Допущения

- Один пользователь запускает пример локально; требований к высокой нагрузке нет.
- Все данные синтетические и остаются в браузере.
- Поддержка рассчитана на актуальные Windows, Linux и macOS с Node.js 22+.
- Человеческое решение обязательно; ИИ не принимает требования и код самостоятельно.
- Калькулятор показывает обучение процессу, а не готовность банковского продукта.

## Журнал решений

1. **Один репозиторий и шесть папок.** Отдельные репозитории усложнили бы сравнение и поддержку.
2. **Одинаковый код во всех вариантах.** Так видно, что зрелость процесса не равна усложнению продукта.
3. **Каждая папка запускается как отдельная страница.** Новичок может изучать одну ступень без скрытой сборки.
4. **TypeScript без прикладного фреймворка.** Для примера важнее прозрачность формулы и проверок.
5. **OpenSpec появляется только на третьей ступени.** Предыдущие правила и два ревью сохраняются.
6. **ИИ оставляет проверяемый след.** В примере фиксируются вход, замечания и ручное решение, но не секреты и не полный диалог.

## Риски и ограничения

- Дублирование кода между папками намеренное: оно делает каждую ступень самостоятельной.
- Доказательства ревью учебные; реальный проект должен использовать правила защиты веток и обязательные проверки платформы.
- Формула аннуитетного платежа упрощена до учебного примера и не учитывает комиссии, страховки и график досрочных платежей.

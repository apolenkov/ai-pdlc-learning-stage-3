# Ступень 2-ИИ — предпроверка перед двумя ревью

**Ветка:** параллельное расширение базовой ступени 2. Она не наследует `1-ИИ` и не обязательна для перехода к базовой ступени 3.

Сначала выполните корневой быстрый старт. Все npm-команды запускайте из корня репозитория.

OpenSpec CLI на этой ступени ещё не используется. Работа идёт с [`specification.md`](specification.md) через [шаблон запроса на слияние](../.github/pull_request_template.md).

## Порядок

1. Автор обновляет спецификацию и тесты.
2. ИИ выполняет предпроверку по [`ai/pre-review.md`](ai/pre-review.md).
3. Автор проверяет замечания и фиксирует решения.
4. Другой аналитик выполняет ревью аналитика и фиксирует решение в [`review/01-analyst-review.md`](review/01-analyst-review.md).
5. Только после него разработчик или архитектор выполняет техническое ревью и фиксирует решение в [`review/02-technical-review.md`](review/02-technical-review.md).
6. Автор из корня запускает `npm run validate:structure`, `npm run validate:links` и `npm run check`, затем связывает Pull Request с Jira.

CI подтверждает структуру и ссылки, но не заменяет обязательные человеческие ревью.

## Результат

Критерии человеческой приёмки совпадают с базовой ступенью 2. Замечания ИИ разобраны до человеческих ревью; два решения разных людей получены последовательно, а ИИ не входит в число согласующих.

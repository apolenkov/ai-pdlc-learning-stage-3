# Ступень 2-ИИ — предпроверка перед двумя ревью

**Ветка:** параллельное расширение базовой ступени 2. Она не наследует `1-ИИ` и не обязательна для перехода к базовой ступени 3.

Сначала выполните корневой быстрый старт. Все npm-команды запускайте из корня репозитория.

## Порядок

1. Автор обновляет спецификацию и тесты.
2. ИИ выполняет предпроверку по `ai/pre-review.md`.
3. Автор проверяет замечания и фиксирует решения.
4. Другой аналитик проводит ревью содержания.
5. После него разработчик или архитектор проводит техническое ревью.
6. Автор из корня запускает `npm run check` и связывает Pull Request с Jira.

## Результат

Замечания ИИ разобраны до человеческих ревью. Два решения разных людей получены последовательно; ИИ не входит в число согласующих.

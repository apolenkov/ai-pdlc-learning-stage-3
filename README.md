# Эталон SDD: кредитный калькулятор

Один синтетический калькулятор показывает три накопительные ступени процесса. На каждой ступени есть базовый вариант и параллельный вариант с ИИ.

```text
1. Шаблон в Git ──→ 2. Два ревью ──→ 3. OpenSpec
       │                   │                │
       └→ 1-ИИ             └→ 2-ИИ          └→ 3-ИИ
```

Базовая цепочка идёт по верхней строке. Вариант с ИИ наследует только свою базовую ступень: `2` не требует прохождения `1-ИИ`, а `3` не требует `2-ИИ`.

## Старт с чистого компьютера

### 1. Проверьте инструменты

Нужны Git, Node.js 22 или новее и npm. Команды одинаковы в PowerShell, Terminal и Bash:

```bash
git --version
node --version
npm --version
```

Ожидаемый результат: Git показывает версию, Node.js — `v22` или новее, npm — номер версии. На ступенях 1 и 2 OpenSpec CLI не используется. Для ступени 3 нужная версия OpenSpec установится локально вместе с зависимостями.

### 2. Скачайте репозиторий

```bash
git clone https://github.com/apolenkov/sdd-guide-credit-calculator-stage-3.git
cd sdd-credit-calculator-example
npm install
```

`npm install` выполняется один раз из корня репозитория. Внутри папок ступеней нет `package.json`, поэтому запускать установку там не нужно.

Для ступени 3 проверьте локальную версию:

```bash
npm exec openspec -- --version
```

Ожидаемый результат: `1.11.0`.

### 3. Проверьте и запустите пример

```bash
npm run check
npm run dev
```

Откройте <http://127.0.0.1:4173/>. На странице должны быть три ступени, в каждой — базовый вариант и вариант с ИИ.

Выберите «1. Шаблон в Git» или сразу откройте <http://127.0.0.1:4173/01-template-git/>. Для значений 3 000 000 ₽, 16% и 240 месяцев ожидаемый ежемесячный платёж — 41 738 ₽.

### 4. Работайте с выбранной ступенью

Например, для первой базовой ступени:

```bash
cd 01-template-git
```

Прочитайте `README.md`, измените спецификацию или код, затем вернитесь в корень и повторите проверку:

```bash
cd ..
npm run check
```

## Три ступени и их ИИ-варианты

| Ступень | Базовая ветка | Параллельная ветка с ИИ |
|---|---|---|
| 1. Шаблон | [`01-template-git`](01-template-git/): Markdown-спецификация и версия в Git | [`01-ai`](01-ai/): базовая ступень 1 + подготовка черновика с ИИ |
| 2. Ревью | [`02-review`](02-review/): базовая ступень 1 + ревью аналитика, затем техническое ревью | [`02-ai`](02-ai/): базовая ступень 2 + ИИ-предпроверка до двух ревью |
| 3. OpenSpec | [`03-openspec`](03-openspec/): базовые ступени 1–2 + управляемое изменение OpenSpec | [`03-ai`](03-ai/): базовая ступень 3 + общий контекст и ИИ-предпроверка |

Код калькулятора во всех шести папках одинаков. Меняется процесс подготовки, проверки и сопровождения изменения.

## Что считается готовым

- `npm run check` завершается без ошибок;
- все шесть страниц считают платёж одинаково;
- текущие и архивные артефакты OpenSpec проходят строгую проверку;
- в каждой папке есть инструкция, ожидаемый результат и доказательства проверки;
- пример не содержит корпоративных данных, секретов и внешних интеграций.

Проект учебный: расчёт — не банковское предложение.

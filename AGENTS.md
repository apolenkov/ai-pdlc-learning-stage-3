# Правила ступени 3

- Учебную работу ведите в персональной ветке. Не отправляйте её напрямую и не сливайте в общую main эталона; после review сохраните ветку и закройте учебный PR без слияния. Сопровождение эталона владельцем — отдельная задача.

- Действующие требования находятся в openspec/specs; история — в openspec/changes/archive.
- Это repo-local OpenSpec: команды из корня не требуют регистрации Store.
- Код находится в src, тесты — в test. ИИ использует эти же файлы.
- Начните с README и относящейся к заданию спецификации. Не добавляйте функции ради прохождения проверки.
- Для изменения поведения используйте стандартный OpenSpec Change и человеческое review перед реализацией.
- Проверяйте npm run check. Результаты ручной проверки не придумывайте.
- Не запускайте долгоживущий dev-сервер как блокирующий шаг выполнения задания.
- Не сохраняйте секреты, персональные данные и рабочие корпоративные документы.

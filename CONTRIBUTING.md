# Работа с примером

Следуйте README из корня репозитория. Создайте свою feature-ветку от актуальной main. Для отчёта ступени 3 изменяется review.md; для изменения поведения сначала согласуется OpenSpec Change.

Перед PR выполните npm run check и необходимые ручные сценарии. Сначала другой аналитик проверяет требования и выводы, затем разработчик или архитектор — реализуемость и доказательства. Замечания и решения остаются в PR; в Jira хранится ссылка.

Сборка для публикации создаётся npm run build. Публикация выполняется отдельно владельцем репозитория. Не добавляйте заранее заполненные одобрения или результаты тестов, которые не запускались.

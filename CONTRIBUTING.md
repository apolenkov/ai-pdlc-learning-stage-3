# Как проходить пример

1. Создайте ветку вида `training/<имя>-<ступень>`.
2. Работайте только в выбранной папке.
3. Запустите `npm run check`.
4. Создайте Pull Request и укажите папку ступени.
5. Начиная со ступени 2 получите два подтверждения по порядку:
   - другой аналитик проверяет содержание;
   - разработчик или архитектор проверяет реализуемость.
6. Добавьте ссылку на Pull Request в учебную задачу Jira.

Не добавляйте токены, персональные данные и рабочие документы. ИИ-вывод всегда считается черновиком до человеческой проверки.

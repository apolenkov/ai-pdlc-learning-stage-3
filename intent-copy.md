# Совместимость старого адреса

[Обращение и ответы](request-and-answers.md) — источник фактов упражнения;
[пример разбора](examples/clear-calculation-result.md) показывает один способ
оформить смысл и не является второй версией фактов. В рабочей ветке создайте
один изменяемый файл `intents/clear-calculation-result.md` по [общему шаблону](intent-template.md)
и продолжайте его между R1–R3. Этот адрес оставлен только для старых ссылок.

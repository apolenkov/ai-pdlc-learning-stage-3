# Совместимость старого адреса

Учебный материал больше не требует отдельной копии замысла для каждой ступени.
Используйте [исходное обращение](request-and-answers.md), [общий шаблон](intent-template.md)
и единый [разобранный пример](examples/clear-calculation-result.md). В своём рабочем
репозитории создайте один файл `intents/clear-calculation-result.md` и продолжайте
его между R1–R3. Этот файл оставлен только для старых ссылок.
